### 🚀 Projects

#### 1. AI Smart Glass
Expanded an AI-powered smart glass that captures images using ESP32-CAM and sends them to a Python FastAPI server for OCR, NLP, and Text-to-Speech processing. Built a client-server architecture using HTTP, integrating HTML for server interaction and ESP32-PICO-D4 with a bone-conduction speaker for real-time audio output.
- **Technologies:** Embedded C, Python, FastAPI, HTML, ESP32-CAM, ESP32-PICO-D4, PaddleOCR, NLP, HTTP, Text-to-Speech

#### 2. Edge-Intelligent IoT Framework For Adaptive Micro Air-Quality Bubbles Enabling Real-Time Personal Safety Zones
Enhanced an ESP32-based IoT Personal Safety Zone system for real-time air quality monitoring and adaptive pollutant control using edge computing. Achieved low-latency prediction with up to 50% PM2.5 and VOC reduction in an energy-efficient closed-loop design.

#### 3. Automated Vision System Using YOLO for Identification and Classification of Marine Phytoplankton
Developed a YOLO-based vision system for detection and classification of marine phytoplankton from microscopic images. Trained and evaluated a custom model for multi-class phytoplankton identification and automated analysis.
- **Technologies:** Python, OpenCV, CNN, YOLOv8
